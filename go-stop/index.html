06｜GO / STOP

GO / STOP Case Study

基本手法本体とは分離したケーススタディ。値幅とSetupの崩れを見る。

CASE 01｜ENTRY方向に上位MAがある

例: H4 SMA20 ≒ H1 MA75付近

重要: 上位MAがある = STOP ではない。ENTRY地点から障害まで十分な値幅が残っているかを見る。
  • GO 障害まで距離あり → そこまでをTargetとしてTrade可能
  • STOP 障害が近すぎる → 値幅不足

CASE 02｜Setup崩れ

  • D1基準ライン割れ
  • H1 SMA20との関係崩れ
  • M15 MA75 / MA100側へ潜る
  • Granvilleとしての組み立て崩れ
