03｜Dow

Dow理論 ― 実用ページ

「どうして、そこで安値が切り上がったと判定しているの？」と疑問を持った方はいませんか？

本ページでは、現代のTechnical AnalysisにおけるDow Theoryの Trend構造を基準として、高値・安値双方の更新から転換を整理します。

高値・安値と、切り上げ・切り下げ

Dow理論では、Chartの高値と安値がどのように推移しているかを見る。

高値・安値が前より高い位置にできることを「切り上げ」。 前より低い位置にできることを「切り下げ」という。

  • 上昇Trend：高値切り上げ ＋ 安値切り上げ
  • 下降Trend：高値切り下げ ＋ 安値切り下げ

重要原則

重要: Trendは、明確な転換サインが出るまで継続すると考える。

価格が一度逆方向へ動いたことだけでTrend転換とは判断しない。 高値側・安値側の両方の構造を確認する。

押し安値と戻り高値

押し安値: 上昇中に一度下げ、そこから再び高値を更新したことで確定する安値。

戻り高値: 下降中に一度上げ、そこから再び安値を更新したことで確定する高値。

谷ができた瞬間に押し安値が確定する、山ができた瞬間に戻り高値が確定する、とは考えない。 次の高値更新 / 安値更新によって確定する。

下降 → 上昇｜転換成功

図の赤番号は高値、青番号は安値。

下降Trendでは、高値は赤① → 赤② → 赤③、安値は青① → 青② → 青③と、 高値・安値ともに切り下げている。赤③は下降Trendの戻り高値。

赤③を上抜く → 高値側に上昇への変化が出る → 赤④を形成 → 押して青④を形成 → 再び上昇して赤④を上抜く

赤④を上抜いたことで、青④が押し安値として確定する。 ここで高値切り上げ ＋ 安値切り上げが揃う。

この時点を「下降Trend → 上昇TrendのDow転換完了」として見る。 赤③を最初に上抜いただけでは、転換完了とは判断しない。

下降 → 上昇｜転換失敗

同じ下降Trendから、上昇転換しそうに見えたが完成しなかった例。

赤③を上抜く → 赤④を形成 → 青④を形成

ここまでは上昇転換の途中に見える。

しかし、青④から上昇しても赤④を上抜けない。 そのため、青④が上昇Dowを完成させる押し安値として確定する構造にならず、 高値・安値双方の上昇Dowが完成しない。その後、再び下方向へ進む。

「戻り高値を一度上抜いた」だけでは上昇Dow転換完了ではない。 明確な転換完成が確認できなければ、元のTrendが継続している可能性を見る。

上昇 → 下降｜転換成功

図の赤番号は高値、青番号は安値。

上昇Trendでは、高値は赤① → 赤② → 赤③、安値は青① → 青②と、 高値・安値ともに切り上げている。青②は上昇Trendの押し安値。

青②を下抜く → 安値側に下降への変化が出る → 新しい安値を形成 → 戻して戻り高値候補を形成 → 再び下落 → 直前に形成した新しい安値を下抜く

最後の安値更新によって、直前の山が戻り高値として確定する。 ここで安値切り下げ ＋ 高値切り下げが揃う。

この時点を「上昇Trend → 下降TrendのDow転換完了」として見る。 青②を最初に下抜いただけでは、転換完了とは判断しない。

上昇 → 下降｜転換失敗

上昇Trendから、下降転換しそうに見えたが完成しなかった例。

押し安値を下抜く → 新しい安値を形成 → 戻りを作る

ここまでは下降転換の途中に見える。

しかし、再下落しても直前の新しい安値を更新できない。 そのため、戻りの山が下降Dowを完成させる戻り高値として確定する構造にならず、 高値・安値双方の下降Dowが完成しない。その後、再び上方向へ進む。

「押し安値を一度下抜いた」だけでは下降Dow転換完了ではない。

4枚の図から覚えること

高値だけを見ない。安値だけを見ない。

「切り上がったように見える」「切り下がったように見える」ことと、 「Dowとして確定した」ことは違う。

高値・安値双方の構造が揃い、明確な転換が完成するまでは、 それまでのTrendが継続していると考える。

片落ちダウ

実際のChartでは、高値側だけ、または安値側だけに転換の兆候が先に出ることがある。 しかし片側だけでは、Dow転換はまだ完成していない。

当サイトでは、このような「片側だけを見てDow転換が完成したように扱う状態」を、 分かりやすく揶揄して「片落ちダウ」と表現している。 正式なDow理論の用語ではない。

一般的なDow理論の考え方と、本サイト / TRADE LOGICでの実戦上の扱いを混同しない。

片側の更新だけで転換としない

Web上などでは、高値または安値の片方の更新だけを 転換として表現した図を見かけることがあります。

本サイトでは、そのような片側だけの整理では Dowの転換完成として扱いません。

片割れDowの否定をTradeに利用した実例

押し安値を更新しただけでは、高値の切り下げが成立していないため、 Dow理論上の下降Trendへの転換はまだ完成していません。

この状態を下降Trendへの転換と判断すると、 SHORTを考えやすいポイントになります。

しかし、その後に高値切り下げが成立せず、 反対に高値を更新すれば、この「片割れDow」は否定されます。

完成Chartと、形成瞬間は違う

完成Chartでは安値切り上げに見えても、その安値が形成された瞬間にはまだ押し安値確定ではない。

  • 安値候補形成
  • 更新
  • 確定
  • 上昇構造 / 下降構造
  • 構造破綻 ≠ 反対Trend成立

本手法でのTrade解釈

M15で正式成立する前に、M5 から切り上げを先行判断する。

Formationは、完成したChartを後から見れば結果論として形を認識できるものでもある。 しかし本手法では、Formationの見た目だけを根拠にはしない。

例えばM15②内部で、メジャーなFormationが現れ、右側安値が切り上がり、M5高値更新、M5 Dow成立という値動きを確認する。

筆者は、Dow理論や広く知られたFormationほど市場参加者から認識されやすく、 注目が集まりやすいことで同じような値動きの再現性が高まりやすいと考えている。

重要: 「逆三尊だからENTRY」という単独Signalとしては使わない。 Formation内部でもM5 Dowが成立していることを重視する。 Dow理論そのものと、本手法上のTrade解釈は区別する。主役はロジック。ここは補助ページ。

なぜM15 Dow成立前にENTRYを考えるのか

M15でDow成立を完全に確認してからENTRYすると、 M15③がすでに進行しており、ENTRY位置が遅くなる場合がある。

Formation
↓
M5 Dow成立
↓
M15安値切り上げを先行判断
↓
右肩付近からENTRY

これによってENTRYを一段早く組み立てられれば、

  • ENTRYからLoss Cutまでの距離を抑えやすい
  • M15③の値幅をより大きく確保しやすい
  • Risk / Rewardの改善につながる

早くENTRYすること自体が目的ではない。 目的は、Loss Cutへの対策とRisk / Rewardの改善を含めたTrade組み立てである。

ロジック該当箇所へ

なぜDowを使うのか

Dow理論は、多くの市場参加者の分析・Trade Logicに組み込まれている。

筆者は、それだけ多くの参加者が著名な理論を利用していることで、 同じ価格構造や反応が繰り返されやすくなり、再現性が高まっていると感じている。

さらに筆者は少し大げさに、 「Dowは、単なる理論というよりChart上に繰り返し現れる現象に近い」 と捉えている。
