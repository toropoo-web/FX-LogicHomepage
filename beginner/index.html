BEGINNER LEARNING ROADMAP

初心者向け｜FX・スキャルピング学習スケジュール

FX初心者から、最終的に自分でChartを見て判断できる状態を目指します。 期間は決めません。各STEPを理解し、実際のChart上で確認できるようになったら次のSTEPへ進みます。

GOAL: 未知のChartでも、環境認識 → 方向 → ENTRY / WAIT / SKIP を自分で考え、その理由を説明できること。
外部YouTubeは参考教材です。当サイトのTRADE LOGICの定義と同一であるとは限りません。 流れは、基礎教材 → 当サイトでの解釈・実Chart確認 → 公開TRADE LOGIC です。

STEP 12｜実Chart練習

最終段階では、答えを先に見ずにChartを見る。

確認する順序

  1. 環境認識
  2. Trend / Direction
  3. 現在位置
  4. ENTRY候補
  5. 障害物
  6. ENTRY / WAIT / SKIP

GOAL

「上がる・下がる」を当てることではなく、 なぜENTRYするのか、なぜ待つのか、なぜ見送るのかを自分で説明できる状態を目指す。
