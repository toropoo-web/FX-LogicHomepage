Trade実例 / 過去検証

「キレイなChartしか載せてない？」と思った方へ

その通りです。筆者は、キレイな形を選んでTradeしています。

条件がキレイに揃ったポイントほど、レートが素直に伸びやすいと考えています。逆に、形が崩れていたり判断材料が噛み合っていない場面では、Tradeリスクが増えます。

目的は、どんなChartでもENTRYを探すことではない。
条件が揃うまで待ち、再現性の高いキレイなポイントを探す。それもこの手法の一部。

片割れDowの否定からLONGを組み立てた例

Dow理論・片割れDow否定を利用したTrade組み立て例です。 勝ちTrade紹介そのものではなく、公開Logicを過去Chartでどう組み立てたかを確認する教材です。

1. 環境認識

H1が安値を更新し、 下向きか？というDow理論の「片割れ」が形成されたポイント【A】。

2. H1レベルの安値切り上げ

その後、H1レベルで安値切り上げポイント【B】を形成。

3. M15逆三尊

このポイントで、 まだ高値を更新していないM15レベルの逆三尊を形成。

4. 注目したポイント

4-1.

価格がH1 SMA20を上抜いていた。

4-2.

【A】の安値を割らずに、 M15（H1と同時）の戻り高値を更新すれば、 【A】で形成された片割れDowを否定することになると想定。

5. 【C】UpDateStall

この場所でUpDateStallが発生。 H4 Short Candleとなり、 H4 SMA5にもSupportされた。

6. 【D】M5 Double Bottom

【4-2】の高値更新へ向かう動きとして、 M5 Double Bottom形成後、 高値を更新したポイントでLONG ENTRY。

過去検証

UpDateStall → Granville → Ascending Triangle

MA・Granville・Formation・時間軸の整合を利用したTrade組み立て例です。 勝ちTrade紹介そのものではなく、公開Logicを過去Chartでどう組み立てたかを確認する教材です。

1. UpDateStall Signal点灯

H4でUpDateStallを確認。 ここを起点として、その後の値動きを観察。

2. 上昇するH4 SMA5にGranville

H4 SMA5は上向き。

価格がH4 SMA5付近まで押したあと、 再び上方向へ動く形を確認。

3. GranvilleがAscending Triangleとなった

H4 SMA5への押しを下位時間軸で見ると、 安値を切り上げながら 上値を繰り返し試す Ascending Triangleを形成。

つまり、

H4では Granville
↓
下位時間軸では Ascending Triangle

として、 同じ値動きを異なる時間軸から確認できる。

4. M15 / H1 Perfect Order

M15・H1ともにMAが上方向へ整列。

ただし、 H4 SMA5自体が上昇しているため、 Perfect Order単独をENTRY Signalとはせず、 上位足から下位足まで 上方向へ整合していることの確認材料として扱う。

この過去検証のポイント

UpDateStallだけでENTRYしたのではありません。
UpDateStall
↓
H4 SMA5 Granville
↓
下位足 Ascending Triangle
↓
M15 / H1 上方向への整合

という複数の見方が 同じ方向を示したところから Tradeを組み立てています。

特に、 「H4でGranvilleとして見える値動きが、 時間軸を下げるとAscending Triangleとして見える」 ことを確認できる過去検証例です。
